# Topo v0.9.9

Topo v0.9.9 focus on critical data safety hardening, security review fixes, system health monitoring enhancements, and deep feature expansions across Clean, Uninstall, and Optimize modules. It addresses 12 correctness and data loss issues, expands system cleanup categories, and integrates Swap & ZRAM monitoring.

## Highlights

### Safety & Correctness Hardening (12 Security Review Fixes)
- **Safe Trash Fallback Protection (C1)**: `safe_remove()` no longer silently falls back to permanent deletion when moving files to trash fails, avoiding unintended permanent data loss.
- **Nested Activity Inspection (C2)**: `clean_path_by_age()` recursively checks nested file mtime before deleting directory structures, preventing deletion of active project subdirectories.
- **Narrowed Orphan Scope (H1)**: Restricted orphaned app residue detection scope to `~/.cache` only (excluding `~/.config` and `~/.local/share` to protect user app configuration data).
- **Symlink Size Accuracy (H2)**: Updated `get_size()` to enforce `follow_symlinks=False`, preventing symlink size inflation and infinite recursive loops.
- **Desktop Section Parsing Guard (H3)**: `.desktop` entry parser now strictly terminates when encountering non-primary section headers (`[Desktop Action ...]`, `[Desktop Entry]`).
- **TOCTOU Guard (M1)**: Implemented re-resolution verification before actual file removal to prevent time-of-check to time-of-use symlink attacks.
- **Safer Cleanup Wrappers (M2-M5)**:
  - Migrated thumbnail cleanup to use `safe_remove()` instead of raw `shutil.rmtree()`.
  - Deduplicated project purge build targets by canonical resolved paths.
  - Converted temp directory cleanup to `clean_path_by_age()` age-based sweeping.
  - Enhanced systemd user service cleanup to inspect all `ExecStart` binary targets.
- **ANSI Terminal Control (L1)**: Replaced `os.system('clear')` with the standardized `CLEAR_SCREEN` ANSI constant. Extracted `TRASH_UNAVAILABLE_REASON` constant and consolidated top-level imports.
- **Robust Output Size Parsing**: Added `ValueError` protection in `parse_size_to_bytes()` to gracefully handle non-numeric unit matches (such as APT `... MB` truncation strings) without crashing during package cleanup.

### Clean & Package Manager Expansions
- **Old Linux Kernel Purging**: Added `clean_old_kernels()` to safely remove old kernel packages across APT and DNF package managers while preserving running + latest kernel.
- **Log Rotation Cleanup**: Added `clean_rotated_logs()` to purge compressed (`*.gz`, `*.xz`, `*.bz2`) and rotated (`*.old`, `*.1`) logs in `/var/log`.
- **User Logs & Editor Backups**: Added `clean_user_logs()` and `clean_backup_files()` to clean `~/.xsession-errors`, `Xorg.log.old`, and editor swap files (`*~`, `*.bak`, `*.swp`).
- **IDE & Gaming Shader Caches**: Added `clean_ide_caches()` (VS Code, Cursor, JetBrains) and `clean_steam_shader_cache()` (Steam, Proton, Mesa, NVIDIA).
- **Developer Tools**: Added `clean_java_caches()` (Gradle/Maven) and `clean_python_pycache()` scanning.
- **Optimized DNF Cache Purging**: Changed DNF cache cleaning from `dnf clean all` to `dnf clean packages`, preserving repository metadata to eliminate redundant downloads on subsequent updates.

### Uninstall Module Enhancements
- **Launcher & Icon Residue Sweep**: `find_residue_paths()` automatically detects matching `.desktop` launchers in `~/.local/share/applications/` and icon assets in `~/.local/share/icons/` and `pixmaps/`.
- **Systemd User Service Cleanup**: Automatically locates leftover user services in `~/.config/systemd/user/*.service` and triggers `systemctl --user daemon-reload` upon removal.

### Optimize Task Restructuring
- **New System Maintenance Routines**: Added `run_sysctl_optimize` (`swappiness=10`), `run_tmpfiles_cleanup`, `run_ldconfig`, `run_locale_gen`, `run_man_db_refresh`, `run_flatpak_repair`, `run_tracker_miner_reset`, and `run_package_repo_refresh`.
- **Removed Controversial Maintenance Tasks**: Removed `run_dns_flush` (handled by `systemd-resolved`) and `run_memory_opt` (`drop_caches`), and migrated thumbnail cleanup into Clean (`clean_thumbnails`).

### System Health Status (Swap & ZRAM)
- **Swap Usage Monitoring**: Added `get_swap_info()` to read Swap usage and display real-time usage progress bars in `topo status`.
- **ZRAM Compression Insights**: Added `get_zram_info()` to read `/sys/block/zram0` compression metrics, displaying compressed RAM size, raw size, and compression ratio (e.g., `51.2x ratio`).

# Topo v0.9.9 中文重点

Topo v0.9.9 版本专注于数据安全防护、安全审查修复、系统健康状态监控增强以及 Clean / Uninstall / Optimize 模块的深度扩充。本版本消除了 12 项潜在的数据安全与功能隐患，显著扩充了空间清理与应用卸载能力，并集成了 Swap 与 ZRAM 压缩内存监控。

### 核心改进

- **安全加固与正确性修复（12 项 Security Review 修复）**：
  - **移至回收站失败安全保护 (C1)**：`safe_remove()` 在移至回收站失败时不再静默降级为永久删除，防止意外破坏用户重要文件。
  - **嵌套文件活动递归检查 (C2)**：`clean_path_by_age()` 在清理空目录结构前递归检查子文件的修改时间（mtime），防止误删存在活跃子文件的工程目录。
  - **收紧孤立残余扫描范围 (H1)**：将应用残余扫描收紧至仅限 `~/.cache`（排除 `~/.config` 和 `~/.local/share`），切实保护用户的应用配置与数据。
  - **符号链接空间计算准确性 (H2)**：`get_size()` 统一采用 `follow_symlinks=False`，防止软链接引发的空间虚高与无限递归死循环。
  - **Desktop 节解析中断控制 (H3)**：`.desktop` 节解析器在遇到非主节头（如 `[Desktop Action]`）时严格终止解析，避免主键解析错乱。
  - **TOCTOU 防御防护 (M1)**：在实际执行文件物理删除前增加路径重新解析校验，防御竞争条件下的符号链接攻击。
  - **更安全的清理封装 (M2-M5)**：缩略图清理改用 `safe_remove()` 包装；项目清理按真实路径去重构建产物；临时目录改用按年龄平滑清理；Systemd 卸载校验全部 `ExecStart` 目标文件。
  - **终端转义码规范 (L1)**：使用 `CLEAR_SCREEN` 常量替换 `os.system('clear')`，提取 `TRASH_UNAVAILABLE_REASON` 常量并整理顶层 import。
  - **包管理器输出解析容错**：在 `parse_size_to_bytes()` 中增加 `ValueError` 异常捕获，容忍包管理器（如 APT 文本省略号 `... MB`）非数值文本的单位匹配，防止实测清理时崩溃。

- **Clean 模块与包管理器清理扩充**：
  - **旧内核清理**：新增 `clean_old_kernels()`，支持在 APT/DNF 系统上清理旧 Linux 内核包，保留当前内核及上一版本。
  - **轮转日志清理**：新增 `clean_rotated_logs()`，安全清理 `/var/log` 下的压缩 (`*.gz`, `*.xz`) 和轮转日志。
  - **用户日志与编辑器备份**：新增 `clean_user_logs()` 和 `clean_backup_files()`，清理 `~/.xsession-errors`、`Xorg.log.old` 及编辑器临时交换文件 (`*~`, `*.bak`, `*.swp`)。
  - **IDE 与游戏着色器缓存**：新增 `clean_ide_caches()`（VS Code, Cursor, JetBrains）和 `clean_steam_shader_cache()`（Steam, Proton, Mesa, NVIDIA）。
  - **开发者工具清理**：新增 `clean_java_caches()` (Gradle/Maven) 与 `clean_python_pycache()` 字节码扫描清理。
  - **优化 DNF 缓存清理**：将 `dnf clean all` 调整为 `dnf clean packages`，保留软件源元数据，避免 `sudo dnf update` 重新下载元数据。

- **Uninstall 应用完全卸载增强**：
  - **快捷方式与图标残余清理**：`find_residue_paths()` 自动识别 `~/.local/share/applications/` 下的 `.desktop` 启动器以及 `~/.local/share/icons/` / `pixmaps/` 中的应用图标。
  - **Systemd 用户服务清理**：自动扫描 `~/.config/systemd/user/*.service` 用户服务，删除后自动执行 `systemctl --user daemon-reload`。

- **Optimize 模块维护任务调整**：
  - **新增实用维护任务**：添加 `run_sysctl_optimize` (`swappiness=10`)、`run_tmpfiles_cleanup`、`run_ldconfig`、`run_locale_gen`、`run_man_db_refresh`、`run_flatpak_repair`、`run_tracker_miner_reset` 及 `run_package_repo_refresh`。
  - **移除争议任务**：移除 `run_dns_flush` 与 `run_memory_opt` (`drop_caches`)，缩略图清理迁移至 Clean 模块。

- **System Health 状态面板（Swap & ZRAM）**：
  - **Swap 内存交换区监控**：新增 `get_swap_info()`，实时读取 Swap 占用情况并在 `topo status` 中以进度条展现。
  - **ZRAM 压缩内存监控**：新增 `get_zram_info()`，读取 `/sys/block/zram0` 压缩指标，显示压缩后物理内存占用、解压前数据量及压缩比率（如 `51.2x ratio`）。
