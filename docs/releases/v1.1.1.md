# Topo v1.1.1

Topo v1.1.1 is a stability, compatibility, and polish release focusing on **openSUSE/Zypper Distribution Support**, **Enhanced Installer Idempotency & Lifecycle Safety**, **Clean Uninstallation Flow**, **CI Test Infrastructure Expansion**, and **Visual Theme Refinements**.

---

## Highlights

### 1. openSUSE & Zypper Distribution Support
- Added native detection and support for openSUSE Leap, openSUSE Tumbleweed, and SUSE Linux Enterprise (`zypper`).
- Added automatic RPM package manager command routing for `zypper install` / `zypper remove` during self-update and removal workflows.

### 2. Installer Lifecycle Safety & Idempotent Execution
- **Atomic Rollback Guarantee**:
  - Validates release manifests and verifies the signature before modifying existing files.
  - Failures during artifact downloads (e.g. static Rust engine binary or source archive) preserve the existing installation intact without corrupting `$HOME/.topo` or leaving broken launcher links.
- **Repeat Installation Optimization**:
  - `curl ... | bash` checks if the requested release is already intact and functional locally; when all conditions match, it skips redundant downloads and network round-trips.
- **Package Conflict Clarification**:
  - Detects existing system package manager installations (`/usr/bin/topo`) and guides users to avoid conflicting user-level installations.
  - Automatically handles Bash/Zsh shell path hashing (`hash -r`) after installation and uninstallation.

### 3. Clean Uninstallation Flow (`topo remove`)
- **Self-Generated State Cleanup**:
  - Clears both `$HOME/.config/topo` and `$XDG_STATE_HOME/topo` directory artifacts created during runtime auditing or whitelist checks.
- **Output Polish & Streamlining**:
  - Removed internal lock contention on `topo remove` to ensure smooth execution.
  - Streamlined removal confirmation prompts and completion summaries.

### 4. CI Workflow & Test Coverage Expansion
- **Installer Lifecycle Smoke Tests**:
  - Added multi-platform integration tests verifying binary signature checks, atomic upgrade transitions, and rollback mechanisms.
- **Expanded OS Matrix Coverage**:
  - Added CI matrix testing across Ubuntu, Fedora, openSUSE, Alpine, and AlmaLinux containers with Python 3.10 through 3.14.
- **Dedicated Release Validation Workflow**:
  - Separated release-only validation from routine pull-request CI jobs for improved reliability and faster feedback loops.

### 5. Visual Consistency & Style Polish
- **Earth Theme Consistency**:
  - Standardized completion banners across `install.sh` to use the signature adaptive Earth Yellow theme color.
- **Update Check Indicator**:
  - Modernized `topo update` checking status line to use standard `✓` glyph indicators.

# Topo v1.1.1 中文发布说明

Topo v1.1.1 是一个稳定性、兼容性与细节体验优化版本，重点聚焦于 **openSUSE / Zypper 发行版适配**、**安装器幂等性与原子回滚安全保障**、**卸载流程与残留状态清理**、**CI 自动化测试矩阵扩展** 以及 **视觉主题细节润色**。

---

## 主要更新

### 1. openSUSE 与 Zypper 发行版支持
- 原生支持 openSUSE Leap、Tumbleweed 及 SUSE 系列发行版（`zypper` 包管理器）。
- 完善包管理器路由映射，支持通过 `zypper` 自动执行 RPM 包安装、升级与卸载。

### 2. 安装器生命周期安全与幂等执行 (`install.sh`)
- **原子回滚保障**：
  - 下载验证采用 Fail-Closed 策略，在签名与哈希校验通过前不触碰旧版本运行文件。
  - 下载中断或引擎文件损坏时完整保留原有运行版本与软链接，不残留临时文件。
- **重复安装免下载**：
  - 当本地已存在且完整安装目标 Release 时，自动跳过重复下载与网络开销。
- **系统包冲突与 Shell 缓存处理**：
  - 精准识别系统级包安装（`/usr/bin/topo`），避免与用户级脚本冲突。
  - 在安装与卸载完成后自动刷新 Shell 命令缓存（`hash -r`）。

### 3. 彻底卸载与残留清理 (`topo remove`)
- **运行期临时状态清理**：
  - 卸载时同步清理配置目录（`$HOME/.config/topo`）及审计状态目录（`$XDG_STATE_HOME/topo`），做到真正干净无残留。
- **解除多余锁限制与输出美化**：
  - 移除 `remove` 命令对互斥锁的强制依赖，简化确认提示与完成反馈。

### 4. CI/CD 测试体系扩展
- **安装器集成回归测试**：
  - 新增安装脚本签名校验、原子升级与异常回滚单元测试套件。
- **多发行版矩阵覆盖**：
  - 扩展 GitHub Actions 测试矩阵，覆盖 Ubuntu、Fedora、openSUSE、Alpine、AlmaLinux 等环境与 Python 3.10~3.14。
- **独立 Release 校验流水线**：
  - 拆分 Release 专属验证工作流，提升 CI 构建效率与发布稳定性。

### 5. 视觉与风格润色
- **经典大地色主题统一**：
  - 安装完成横幅统一使用 Topo 标志性大地色（Earth Yellow）。
- **更新检查图标优化**：
  - 优化 `topo update` 检查更新时的前置状态符号显示。
