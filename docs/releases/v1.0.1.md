# Topo v1.0.1

Topo v1.0.1 is a patch release focusing on uninstall residue detection enhancements, browser profile security safeguards, scanning performance optimizations, and system status dashboard refinements.

## Highlights

### Uninstall & Residue Detection Enhancements
- **Hyphen/Underscore Package Name Parsing**: `find_residue_paths()` automatically extracts prefix targets from package names with separators (e.g., `google-chrome-stable` matches `google-chrome`), ensuring configuration directories like `~/.config/google-chrome` are completely discovered and cleanly uninstalled.
- **Accurate Total App Disk Usage**: Integrated residue path searching (`~/.config`, `~/.local/share`, `~/.cache`) into `UninstallManager`, accurately accumulating total disk footprints (e.g., QQ app binary + chat data + cache) rather than reporting binary sizes alone.
- **Ultra-Fast Uninstall Scanning**: Replaced repeated disk scans with a unified XDG data root index, reducing full uninstall scan latency from **3.5s to ~0.2s**.

### Browser Profile Security & Protected Paths
- **Firefox Profile Path Completion**: Added `.config/mozilla` alongside `.mozilla` to Firefox's `profile_roots` in `browser_cache.py`, preventing accidental cleanup of browser extensions/language packs during `topo clean` and ensuring 100% thorough residue removal during uninstall.
- **IM Account Token Safeguards**: Added `.config/QQ`, `.config/tencent-qq`, `.config/Tencent`, and `.config/WeChat` to `LINUX_PROTECTED_HOME_PATHS`, ensuring cleanup operations never compromise user login sessions or account tokens.

### System Status Dashboard & Clean Refinement
- **Status Dashboard UI Refinement**: Reorganized `topo status` layout into 4 logical blocks (Overview & CPU, Storage & Memory, Hardware & Network, Top Processes), and added real-time Swap & ZRAM compression ratio monitors.
- **Package Manager Size Calculation**: Fixed `clean_package_manager()` to accurately measure APT archive cache and `/var/cache/apt/archives/partial` size diffs.

# Topo v1.0.1 中文重点

Topo v1.0.1 为 Topo 的维护补丁版本，重点对卸载残余目标识别算法、浏览器配置安全防线、卸载扫描性能以及系统状态监控面板进行了精修与增强。

### 核心改进

- **Uninstall 卸载残余检测与匹配增强**：
  - **包名分隔符前缀自动提取**：`find_residue_paths()` 算法新增对带连字符/下划线包名（如 `google-chrome-stable` 匹配 `google-chrome`）的前缀提取，彻底解决了 Chrome、Edge 等包名与配置目录名不一致导致配置残留遗漏的问题。
  - **应用真实磁盘占用累加**：在 `UninstallManager` 中自动搜寻并累加应用在 `~/.config`、`~/.local/share` 及 `~/.cache` 下的数据残余，准确展示应用真实空间占用。
  - **卸载扫描速度提升 (3.5s -> 0.2s)**：构建全局单次 XDG 数据根目录索引，消除重复磁盘 I/O，将全局卸载扫描耗时由 3.5 秒降低至 0.2 秒级。

- **浏览器配置安全防线与敏感路径保护**：
  - **Firefox 配置文件全路径补全**：在 `browser_cache.py` 中补充 `.config/mozilla` 路径定义，在 `topo clean` 时严密防护火狐扩展与语言包，同时保证彻底卸载火狐时的无死角清理。
  - **IM 账号 Token 与登录态防护**：将 `.config/QQ`、`.config/tencent-qq`、`.config/Tencent`、`.config/WeChat` 显式纳入受保护防线，确保垃圾清理决不破坏用户登录凭证。

- **Status 系统状态面板与细节优化**：
  - **Status 界面精简与 ZRAM/Swap 支持**：重构 `topo status` 排版，划分 4 大逻辑板块，补充 Swap 占用与 ZRAM 压缩率检测。
  - **APT 包管理器清理精确统计**：修正 `clean_package_manager()` 对 APT 归档包缓存及 partial 目录物理大小的准确测算。
