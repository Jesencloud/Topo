# Topo v0.9.8

Topo v0.9.8 delivers major code quality, type safety, and performance optimizations. It refactors core caching and TUI rendering modules, eliminates redundant file system scans, caches system tool lookups, and brings `mypy` strictness across all core Python source files.

## Highlights

### Architecture Cleanup & Decoupling
- **Dedicated Scan Cache Module**: Extracted `ScanCache` into `src/core/scan_cache.py` and implemented `ScanCache.discard(path)`, ensuring clean encapsulation without callers mutating internal data structures directly.
- **TUI Uninstall Selector Extraction**: Decoupled the interactive uninstall preview loop into `UninstallPreviewSelector` within `src/ui/navigator.py`. The preview now pre-calculates target selection sizes once during initialization for a smoother user experience.
- **Desktop Entry Parser Reuse**: Created `src/core/desktop_entry.py` to standardize `.desktop` file parsing across app discovery and autostart cleanup routines.

### Type Safety & Static Inspection
- **Zero Mypy Errors (`--check-untyped-defs`)**: Resolved all 25 hidden static type errors across `navigator.py`, `remove.py`, `status.py`, and `apps.py`.
- **Shared Terminal Control Helper**: Extracted `read_sudo_choice()` into `src/core/terminal_state.py`, eliminating duplicate terminal input logic across cleanup and optimization runner modules.
- **Strict CI Checks**: Updated `check.sh` to enforce `mypy --check-untyped-defs src/` on all commit checks.

### Performance & Subprocess Optimization
- **Cached Tool & Binary Resolution**: Wrapped `shutil.which()` calls in `safe_remove()` (for `gio`/`trash-put`) and `_get_core_binary()` with `@functools.cache`, removing hundreds of redundant `$PATH` directory traversals.
- **Single-Pass Project Scanning**: Merged `is_project_root()` and `_recursive_scan()` into a single `os.scandir()` pass in `src/clean/project.py`, reducing filesystem system calls by half during project discovery.
- **Linear $O(N)$ Cache Filtering**: Replaced nested `dirnames.remove()` calls in `app_cache.py` with in-place slice filtering (`dirnames[:] = keep`), eliminating quadratic time complexity in deep cache walks.
- **Faster Age Sweeps**: Updated `clean_path_by_age()` to use `os.scandir()` and `DirEntry.stat(follow_symlinks=False)` to leverage cached stat info from kernel directory entries.

### UX & Installation Hardening
- **First-Time One-Liner Install Fix**: Resolved an issue in `install.sh` where interactive shell PATH resolution failed when installed via `curl | bash` for the first time.
- **Standardized UI ANSI Constants**: Introduced global composite markers (`OK`, `SKIP`, `FAIL`) and terminal control codes (`CLEAR_SCREEN`, `CLEAR_LINE`, `ERASE_BELOW`) in `constants.py`, replacing over 40 hardcoded ANSI sequences.
- **Accurate Removal Reporting**: Added error tracking to `src/manage/remove.py` to inform users if uninstallation encountered partial permission errors instead of displaying a false-positive success banner.

# Topo v0.9.8 中文重点

Topo v0.9.8 侧重于代码质量提升、类型安全强化与底层性能优化。本次版本完成了全局架构解耦、静态类型错误清零、文件系统高频操作缓存以及 UI 交互的精细化修整。

### 核心改进

- **架构解耦与模块重构**：
    - **独立 ScanCache 模块**：将扫描缓存提取至 `src/core/scan_cache.py`，并提供 `ScanCache.discard(path)` 接口，消除外部模块对内部缓存字典的直接改写。
    - **TUI 卸载预览器解耦**：将应用卸载的预览界面抽取为 `UninstallPreviewSelector`（位于 `src/ui/navigator.py`），初始化时一次性计算选中容量，大幅提升渲染流畅度。
    - **通用 Desktop Entry 解析器**：新增 `src/core/desktop_entry.py`，统一自启动与应用识别中对 `.desktop` 配置文件及 `Exec`/`Icon` 键值的解析。

- **类型安全与静态检查加固**：
    - **Mypy 错误清零**：全面修复 `navigator.py`、`remove.py`、`status.py` 及 `apps.py` 中的 25 处类型隐患，开启 `--check-untyped-defs` 严格模式。
    - **提取共享 Sudo 选择逻辑**：将 `runner.py` 与 `optimize.py` 中重复的单键输入逻辑提取至 `src/core/terminal_state.py` 的 `read_sudo_choice()` 中。
    - **CI 门禁增强**：更新 `check.sh` 脚本，在提交检查中强制开启更严格的 Mypy 类型检查。

- **极致性能与 IO 优化**：
    - **系统工具查找缓存**：在 `safe_remove()`（检查 `gio`/`trash-put`）和 `_get_core_binary()` 上引入 `@functools.cache`，消除高频操作中数百次对 `$PATH` 环境变量的重复文件查找。
    - **单 Pass 项目根目录扫描**：合并 `project.py` 中的 `is_project_root()` 与 `_recursive_scan()` 的两次 `scandir` 调用，使项目查找过程中的目录系统调用降低 50%。
    - **消除 $O(N^2)$ 遍历隐患**：将 `app_cache.py` 深入下钻时的 `dirnames.remove()` 重构为 $O(N)$ 级别的列表切片替换。
    - **高效年龄清理**：`clean_path_by_age()` 改用 `os.scandir()` 与 `DirEntry.stat(follow_symlinks=False)`，利用内核返回的目录项缓存 stat 信息提升扫描速度。

- **体验细节与安装加固**：
    - **一键安装管道修复**：修复 `install.sh` 在通过 `curl | bash` 首次管道安装时由于 PATH 未刷新导致无法即刻使用命令的问题。
    - **标准化 ANSI 终端转义码**：在 `constants.py` 中定义 `OK`、`SKIP`、`FAIL`、`CLEAR_SCREEN` 等命名常量，替换全项目 40+ 处硬编码转义码。
    - **卸载状态真实反馈**：加固 `remove.py` 逻辑，在卸载遇到权限问题或局部失败时给出准确的错误提示，不再盲目提示全部成功。
