# Topo v1.0.3

Topo v1.0.3 is a feature, safety, and reliability release introducing standalone CLI discovery (such as `agy`), deduplicated size calculations, dead/zombie code elimination, Tach architecture boundary enforcement, generic non-hardcoded process termination, complete XDG/Snap path coverage, and robustness & maintainability refactoring.

## Highlights

### Standalone CLI & `agy` Discovery & Size Deduplication
- **Script-Installed CLI Tool Scanning (`~/.<cmd>`)**: Expanded Pattern A standalone CLI discovery to recognize dot-directories in user home (`~/.<cmd>`, such as `~/.codex` and `~/.agy`), allowing CLI tools installed via official shell scripts to be correctly discovered, measured, and uninstalled.
- **Install Directory Size Deduplication**: Fixed size calculation during full uninstall scans by excluding `install_dir` from residue sum calculations, resolving double-counting bugs where CLI app sizes were reported as twice their actual footprint.

### Dead & Zombie Code Elimination
- **Zero-Invocation Dead Code Wipe**: Removed unused functions `get_ssd_info()` and `get_terminal_width()`.
- **Zombie Function & Test Cleanup**: Cleaned up 4 zombie helper functions (`_get_app_localized_name()`, `is_project_root()`, `get_package_manager_commands()`, `_should_update()`) and removed 7 outdated zombie test cases (reducing test count from 320 to 313 clean tests).

### Tach Architecture Boundary Governance
- **Module Dependency Guard (`tach.toml`)**: Initialized dependency rules for Topo's 5 core modules (`src.core`, `src.ui`, `src.clean`, `src.manage`, `src.main`), enforcing strict layer isolation and enabling `pytest --tach` incremental test execution.

### Generic Process Auto-Discovery & Termination
- **Generic 4-Tier Process Discovery (No App-Specific Hardcoding)**:
  - **Dynamic `/proc` & `fuser` File Occupation Inspection**: Queries PIDs occupying an app's residue data directories (e.g. `~/.config/xxx`) and extracts binary process names from `/proc/<pid>/comm`.
  - **Comprehensive `.desktop` `Exec` Binary Parsing**: Parses executable names from all associated desktop launchers.
  - **Token Splitting & Prefix Stripping**: Automatically splits hyphens/underscores and strips generic prefixes (e.g. `google-chrome-stable` -> `chrome`, `org.telegram.desktop` -> `telegram.desktop`).
- **Guaranteed Complete Uninstallation**: Prevents running applications (such as Linux QQ or WeChat) from re-writing configuration handles after binary package removal.

### XDG State & Snap Path Coverage
- **Complete XDG & Snap Search Roots**: Added `~/.local/state` (XDG_STATE_HOME) and `~/snap` (Snap sandbox data) to `find_residue_paths()` search roots and one-pass pre-scanning index, ensuring CLI session logs and Snap package residues are fully discovered and purged.

### Correctness, Safety & Maintainability Refactoring
- **Subprocess Timeout & Safe Deletion Enforcement**: Added `timeout=300` to package management calls in `remove.py` and `update.py`. Unified all self-uninstallation deletions through `safe_remove()` with TOCTOU checks.
- **Symlink Recursion Defense**: Added `follow_symlinks=False` to `project.py` directory traversal to prevent infinite loops from cyclic symlinks.
- **Network & Config OSError Protection**: Wrapped fallback `curl` in `update.py` with `try...except (OSError, SubprocessError)` to prevent crashes in offline environments. Protected `save_config()` and whitelist operations against read-only filesystems.
- **Guard Clause Flattening**: Reduced nesting depth in `install.py` from 7 levels down to 4 using early `continue` guard clauses.

# Topo v1.0.3 中文重点

Topo v1.0.3 为 Topo 的功能、安全与可维护性重要版本，重点提升了独立 CLI 工具感知（如 `agy`）、死代码清理、Tach 架构边界治理、通用常驻进程无硬编码自动发现与查杀、XDG 状态与 Snap 路径全量覆盖，以及代码正确性与可维护性重构。

### 核心改进

- **独立 CLI 应用与 `agy` 发现及空间精准计算**：
  - **Shell 官方脚本安装应用 (`~/.<cmd>`)**：`app_manager.py` 的 Pattern A 检索机制新增对用户主目录点文件夹（如 `~/.codex`、`~/.agy`）的识别与自动关联，支持各类官方 Shell 脚本工具的扫描、空间计算与连根拔起卸载。
  - **占用空间精准去重**：修复卸载扫描中 `install_dir` 被作为残余再次计入总大小的缺陷，解决独立 CLI 工具尺寸显示翻倍的问题。

- **死代码与僵尸代码清理**：
  - **死函数擦除**：通过 AST 解析与交叉引用审计，移除了 2 处零调用的死函数 `get_ssd_info()` 与 `get_terminal_width()`。
  - **僵尸函数与僵尸测试清理**：清理了 4 处仅在测试中被调用的僵尸辅助函数（`_get_app_localized_name()`、`is_project_root()`、`get_package_manager_commands()`、`_should_update()`），并同步删除 7 个废弃的僵尸测试用例。

- **Tach 模块架构边界治理**：
  - **模块依赖契约 (`tach.toml`)**：为 Topo 的 5 大核心模块 (`src.core`, `src.ui`, `src.clean`, `src.manage`, `src.main`) 建立了依赖隔离规则，实现了 `tach check` 自动化依赖校验及 `pytest --tach` 增量测试。

- **通用常驻进程无硬编码自动发现与杀除**：
  - **4 重通用进程发现机制**：
    - **`/proc` & `fuser` 动态文件占用反查**：卸载前自动查询正读写该 App 残留目录（如 `~/.config/xxx`）的进程 PID，并从 `/proc/<pid>/comm` 提取真实二进制进程名。
    - **全量 `.desktop` `Exec` 解析**：自动从快捷方式解析真实可执行文件名。
    - **Token 拆分与前缀剥离**：自动切分横线/下划线及常见前缀（如 `google-chrome-stable` -> `chrome`）。
  - **彻底卸载保障**：解决因包名与常驻进程名不一致（如包名 `linuxqq` 与进程名 `qq`/`qqnt`）导致进程未关停、文件被锁定再次写回配置的问题。

- **XDG 状态与 Snap 路径全量补全**：
  - **补全 `~/.local/state` 与 `~/snap`**：将 `~/.local/state` (XDG 运行状态) 与 `~/snap` (Snap 沙盒数据) 补入 `find_residue_paths()` 与预扫描索引，保证命令行工具 Session 日志与 Snap 应用残余无死角抹除。

- **正确性 (Correctness) 与可维护性加固**：
  - **超时防护与删除安全收拢**：为 `remove.py` 与 `update.py` 补充 `timeout=300` 超时保护；自卸载删除逻辑统一收拢为 `safe_remove()`。
  - **符号链接环路隔离**：在 `project.py` 目录遍历中增加 `follow_symlinks=False` 限制，防止因 Symlink 导致死循环。
  - **网络与文件系统 OSError 写入防护**：为 `update.py` 离线 `curl` 和 `config.py`/`whitelist.py` 写入操作补充 `try...except OSError` 异常捕获。
  - **Guard Clause 扁平化重构**：优化 `install.py` PATH 挂载逻辑，嵌套深度从 7 层降至 4 层。
