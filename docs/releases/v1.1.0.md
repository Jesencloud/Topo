# Topo v1.1.0

Topo v1.1.0 is a feature and quality-of-life release focusing on **Analyze Disk Navigation & Pagination Upgrades**, **Interactive State Preservation across Menus**, **Terminal Sudo Cancellation Safety**, and **Status Dashboard Alignment Improvements**.

---

## Highlights

### 1. Analyze Disk Navigation & Column Alignment
- **Fixed Column Widths on Directory Drill-down**:
  - Unified the item index slot width (2 characters wide) between root and child directory levels.
  - Progress bar, percentage, icon, filename, and file size columns remain strictly stationary without horizontal shift or jitter when drilling into or returning from subdirectories.
- **Hierarchical Navigation State Preservation**:
  - The navigation stack now retains each parent directory's `selected_index` and `current_page`.
  - Child directories always initialize on Page 1 at Item 1, while returning to the parent directory (or falling back on scan error) cleanly restores the exact cursor position and page index.
  - Added boundary clamping and mock compatibility to ensure safe state restoration.

### 2. Smart Multi-Page Navigation & Digit Selection
- **Global Accumulated Numbering**:
  - Item numbers in Analyze Disk now accumulate across pages (Page 1: 1–15, Page 2: 16–30, Page 3: 31–45) for unambiguous item identification.
- **Current-Page Digit Selection & Safety**:
  - Number keys typed by the user strictly match items visible on the current page (e.g. typing `16` on Page 2 toggles item #16; numbers outside the current page range are ignored to prevent accidental hidden selections).
  - Clarified header prompt: `Type numbers for current page or Space to select`.
- **Dynamic Pagination Direction Hints**:
  - Displays context-aware scroll indicators below the list only when additional pages exist:
    - First page: `↓ More items below`
    - Middle pages: `↑ More items above | ↓ More items below`
    - Last page: `↑ More items above`
  - Single-page views omit hints cleanly without extra whitespace.
  - Updated helper prompts: `F: Open Location` (selectable view) and `F: Enter Folder` (root view), with page display formatted as `Page X of Y`.

### 3. Main Menu Return State Retention
- **Active Menu Item Persistence**:
  - Returning from any secondary view (Clean, Uninstall, Optimize, Analyze, Status) now remembers and highlights the previously selected menu item.
  - First launch continues to default to Item 1 (`1. Clean`).

### 4. Robust Terminal State & Sudo Cancellation Safety
- **Clean Ctrl+C Handling during Sudo Confirmations**:
  - Intercepts raw-mode `\x03` during sudo consent prompts (`System caches need sudo...` / `Optimization tasks need sudo...`) and translates it into a standard `KeyboardInterrupt`.
  - Restores terminal cooked mode in the `finally` block before cancellation.
  - Cancels elevation cleanly, avoids prompting for sudo passwords, and safely returns to the Main UI without executing privileged tasks.
- **Linter & Code Hygiene**:
  - Removed unused constant imports and configured Ruff to exclude `.vulture_whitelist.py`.

### 5. Status Dashboard Alignment & Spacing Refinements
- **Unified Overall Status Layout**:
  - `Overall Status:` row now uses standard `_status_row` formatting, aligning perfectly with `Top Processes:` and preceding metrics.
  - Eliminated redundant trailing blank lines between overall assessment and the return prompt.
  - Preserved distinct status icon colors (🌿 / 🟡 / 🔴) without disrupting column width calculations.

# Topo v1.1.0 中文发布说明

Topo v1.1.0 是一个体验与交互质量提升版本，重点聚焦于 **磁盘分析（Analyze Disk）深度导航与分页体验升级**、**主菜单与次级视图状态保持**、**Sudo 授权终端 Ctrl+C 安全退出** 以及 **系统状态页列对齐优化**。

---

## 主要更新

### 1. Analyze 磁盘分析列对齐与层级状态保持
- **消除钻取目录时的横向跳变**：
  - 统一了根目录与子目录的序号槽位宽度（固定 2 字符宽）。
  - 进度条、百分比、文件图标、名称与大小列在进入或返回次级目录时完全固定对齐，彻底消除界面左右抖动。
- **导航栈完整记录光标与分页位置**：
  - 导航栈保存父目录各层的 `selected_index` 与 `current_page`。
  - 进入子目录时自动从第 1 页第 1 项开始；返回上级目录（或遇到扫描错误回退）时精准恢复原有光标和翻页位置。
  - 加入防越界截断处理，保证安全可靠。

### 2. 跨页全局序号与当前页数字键防误选
- **序号全局累计展示**：
  - 列表序号按全局位置累计显示（第 1 页：1–15，第 2 页：16–30，第 3 页：31–45），便于精准识别全局项目。
- **数字键仅匹配当前页项目（防误触）**：
  - 用户输入数字仅作用于当前可见页（例如在第 2 页输入 `16` 选中第 16 项；输入非当前页编号自动忽略，杜绝误选非可见项）。
  - 顶部操作提示更新为 `Type numbers for current page or Space to select`。
- **分页方向动态提示**：
  - 仅在存在上一页或下一页时显示底部提示：
    - 首页：`↓ More items below`
    - 中间页：`↑ More items above | ↓ More items below`
    - 尾页：`↑ More items above`
  - 单页内容不显示多余提示行；快捷键文案优化为 `F: Open Location` / `F: Enter Folder`，页码显示为 `Page X of Y`。

### 3. 主菜单返回位置保持
- **记录上次访问的菜单项**：
  - 从任意子功能（Clean、Uninstall、Optimize、Analyze、Status）返回主菜单后，光标自动停留在上次进入的选项上，无需重新从第一项移动光标。
  - 首次启动仍默认选中第 1 项（`1. Clean`）。

### 4. Sudo 确认阶段 Ctrl+C 安全取消与终端恢复
- **Raw 模式安全捕获中断**：
  - 在 `System caches need sudo...` 与 `Optimization tasks need sudo...` 确认阶段识别 `\x03`（Ctrl+C），触发 `KeyboardInterrupt`。
  - 在 `finally` 块中立即恢复标准终端模式，跳过密码输入并安全返回 Main UI，不执行任何高危提权清理/优化任务。
- **代码规范与 Linter 配置**：
  - 清理未使用常量，并在 `pyproject.toml` 的 Ruff 配置中排除 `.vulture_whitelist.py`。

### 5. 系统状态（Status）面板列对齐与排版优化
- **Overall Status 标准列对齐**：
  - `Overall Status:` 统一采用 `_status_row` 布局计算，与上方的 `Top Processes:` 等各行严格对齐。
  - 去除健康评估与底部返回提示之间的多余空行。
  - 保留 🌿/🟡/🔴 评估图标原有颜色，同时消除 ANSI 颜色代码对列宽测算的潜在干扰。
