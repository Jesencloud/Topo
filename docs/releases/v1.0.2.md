# Topo v1.0.2

Topo v1.0.2 is a release focusing on standalone CLI discovery, size calculation deduplication, orphaned remnant cleanup safety refactoring, and expanded system infrastructure safeguards.

## Highlights

### Standalone CLI Discovery & Size Accuracy
- **Script-Installed CLI Tool Scanning (`~/.<cmd>`)**: Pattern A standalone CLI discovery in `app_manager.py` now recognizes dot-directories in user home (`~/.<cmd>`, such as `~/.codex`), allowing tools installed via official shell scripts (e.g. Codex CLI, Claude CLI, Grok CLI) to be properly discovered and cleanly uninstalled.
- **Install Directory Size Deduplication**: Fixed size calculation during full uninstall scans by excluding `install_dir` from residue sum calculations, resolving double-counting bugs where CLI app sizes were reported as twice their actual footprint (e.g. 766 MiB instead of 383 MiB).

### Safe Orphaned Remnant Cleanup Refactoring
- **Strict Scope Isolation (`~/.cache` Only)**: Refactored `clean_orphaned_remnants()` in `apps.py` to strictly limit orphan scans to `~/.cache` (temporary cache files). Removed automatic scanning of `~/.config` and `~/.local/share` during daily cleanup to eliminate any risk of accidentally deleting user configurations or session data for portable/AppImage applications (such as Clash Verge).
- **Multi-Source `.desktop` Verification**: Integrated system-wide `.desktop` file parsing across `/usr/share/applications`, `/usr/local/share/applications`, `/var/lib/flatpak/exports/share/applications`, and `~/.local/share/applications` using shared parser `get_desktop_exec_command()`.
- **60-Day Inactivity Safety Cutoff**: Added a 60-day `st_mtime` / `st_atime` safety threshold for orphaned cache folders to protect active unlisted applications.

### Expanded System Infrastructure Protection (`system_folders`)
- **Multi-Vendor Hardware & Desktop Framework Protection**: Expanded the `system_folders` exemption list to cover PipeWire/WirePlumber/ALSA audio infrastructure, KDE Plasma/Qt5/Qt6/XFCE desktop toolkits, Intel/AMD/NVIDIA GPU/CPU driver caches, OpenCL/PoCL heterogeneous computing caches, Vulkan shader caches, and GStreamer hardware acceleration pipelines.

# Topo v1.0.2 中文重点

Topo v1.0.2 为 Topo 的功能与安全性版本，重点提升了独立 CLI 工具感知、应用空间计算准确性、孤立清理模块的安全防误删重构，以及系统基础设施白名单防护。

### 核心改进

- **独立 CLI 工具感知与空间精准度提升**：
  - **支持 Shell 官方脚本安装应用 (`~/.<cmd>`)**：`app_manager.py` 的 Pattern A Standalone CLI 检索机制新增对用户主目录点文件夹（如 `~/.codex`）的识别，成功支持 Codex CLI、Claude CLI、Grok CLI 等工具的扫描与彻底擦除。
  - **卸载占用空间精准去重**：修复卸载扫描中 `install_dir` 被作为残余再次计入总大小的缺陷，彻底解决独立 CLI 工具显示占用翻倍（如将 383 MiB 误算为 766 MiB）的问题。

- **孤立残余垃圾安全清理重构 (防误删机制)**：
  - **严格限定 `~/.cache` 纯缓存清理**：重构 `clean_orphaned_remnants()` 算法，**彻底剔除对 `~/.config` 和 `~/.local/share` 的自动例行清理**，彻底消除便携/免安装软件（如 Clash Verge）因缺失系统命令而导致用户配置文件被误判删除的隐患。
  - **多源桌面快捷方式解析复用**：复用 `get_desktop_exec_command()` 对系统全路径（包含 `/usr/share/applications`、`/var/lib/flatpak/exports/` 等）进行 `.desktop` 链路解析。
  - **60 天访问年龄保护门槛**：为 `~/.cache` 孤立清理增加了 60 天 `mtime`/`atime` 活动期保护，自动屏蔽近期使用过的缓存文件夹。

- **扩展系统级硬件与桌面框架防护 (`system_folders`)**：
  - **硬件加速与桌面框架全面覆盖**：将 PipeWire / WirePlumber / ALSA 音频服务、KDE / Qt5 / Qt6 / XFCE 桌面框架、Intel / AMD / NVIDIA 处理器与显卡驱动、OpenCL / Vulkan / GStreamer 硬解加速框架全面纳入系统级保留白名单。
