# Topo v1.0.0

Topo v1.0.0 is the official milestone release of Topo, introducing full cross-distribution compatibility across DEB (Ubuntu/Debian) and RPM (Fedora/RHEL) Linux packaging ecosystems, DNF5 next-generation package manager architecture support, smart system application protection, NPM global & Standalone CLI app uninstallation, and refined disk analysis/cleanup workflows.

## Highlights

### Smart Protection & System Safety Hardening
- **Pre-installed System Apps Protection**: Added comprehensive protection for all default pre-installed desktop apps across GNOME, Fedora, Ubuntu, and Debian (e.g., `ptyxis`, `gnome-calculator`, `gnome-calendar`, `gnome-clocks`, `gnome-weather`, `gnome-maps`, `gnome-boxes`, `loupe`, `snapshot`, `showtime`, `decibels`, `baobab`, `orca`, `papers`, `yelp`, `org.gnome.characters`, Ubuntu meta-packages), ensuring the `Uninstall` module exclusively presents user-installed third-party applications.
- **Core Infrastructure Safeguards**: Expanded system protection lists to block critical development tools (`gcc`, `g++`) and system libraries (`glibc`, `llvm`, `systemd`, `geoclue`, `gcr`, `rygel`, `rust-std`, `openjdk`, `gnome-bluetooth`).
- **Generic Non-GUI Component Interception**: `_is_system_component()` automatically filters non-GUI libraries using prefix (`lib*`, `gsettings-*`, `desktop-file-*`, `shared-mime-*`) and suffix (`*-libs`, `*-devel`, `*-dev`, `*-static`, `*-headers`, `*-plugins`, `*-modules`) pattern matching.

### Uninstall Module Enhancements
- **NPM Global Package Uninstallation**: Fully supports scanning (`npm list -g --json`) and clean removal (`npm uninstall -g`) of scoped and unscoped NPM CLI tools (e.g., `@openai/codex`, `@cloudbase/cli`, `miniprogram-ci`), with automatic removal of empty scope directories.
- **Standalone Native CLI Detection**: Implemented zero-hardcoding dynamic discovery for standalone native CLI executables and Vibe Coding tools (e.g., **Claude Code** `~/.local/share/claude`, **Kimi Code** `~/.kimi-code`, **Grok CLI** `~/.grok`).

### DNF5 Architecture & Package Manager Cache Optimization
- **First-Class DNF5 Support**: Seamlessly supports Fedora 41/44+ DNF5 architecture with automatic resolution of `/var/cache/libdnf5` and `/var/cache/dnf5daemon-server` paths.
- **Repository Metadata Preservation**: Enforced `clean packages` policy across DNF and DNF5. Safely purges downloaded `.rpm` package files while preserving repository metadata indices, preventing slow metadata re-downloads during subsequent `sudo dnf update` runs.
- **Physical Size Measurement**: Integrated pre/post physical directory size diffing in package manager cleanup for precise disk space recovery reporting.

### Analyze Disk Explorer Layering & Visual Refinements
- **Clean Root View Explorer**: Excluded system-level `Dnf Cache` and duplicate `Flatpak App Data` (`~/.local/share/flatpak`) from the Root view in `Analyze Disk`, preventing index noise and double-counting with Home.
- **Tailored Category Icons**: Updated Linux Insights with intuitive visual icons (`📦` Package Managers/Flatpak, `🐳` Docker, `🤖` AI Models, `🕒` Stale Downloads).

### Cross-Distribution Compatibility (DEB & RPM)
- **Multi-Distro Auto-Perception**: Enhanced system platform detection and package management lifecycle across Fedora/RHEL (RPM/DNF/DNF5), Ubuntu/Debian (DEB/APT/dpkg), Arch Linux (Pacman), Snap, and Flatpak.

# Topo v1.0.0 中文重点

Topo v1.0.0 为 Topo 官方里程碑正式版本。本版本全面支持 DEB (Ubuntu/Debian) 与 RPM (Fedora/RHEL) 跨 Linux 发行版生态、新一代 DNF5 包管理器架构、智能预装应用与系统底层防护系统、NPM 全局包与 Standalone CLI 卸载，并重构了磁盘分析与清理体验。

### 核心改进

- **智能防护与系统安全加固**：
  - **预装系统应用全防护**：全面包含了 GNOME、Fedora、Ubuntu 及 Debian 下的默认系统预装套件（包含 `ptyxis` 终端、`gnome-calculator`、`gnome-calendar`、`gnome-clocks`、`gnome-weather`、`gnome-maps`、`gnome-boxes`、`loupe`、`snapshot`、`showtime`、`decibels`、`baobab`、`orca`、`papers`、`yelp`、`org.gnome.characters` 及 Ubuntu 默认元包套件），确保 `Uninstall` 模块**仅展现用户主动安装的第三方应用**。
  - **核心基础设施防护**：扩展防护名录，严密拦截 `gcc`、`g++`（C/C++ 编译器）以及 `glibc`、`llvm`、`systemd` 等系统级底层核心工具。
  - **非 GUI 组件自动拦截**：`_is_system_component()` 通过前缀 (`lib*`, `gsettings-*`, `desktop-file-*`, `shared-mime-*`) 与后缀 (`*-libs`, `*-devel`, `*-dev`, `*-static`, `*-headers`, `*-plugins`, `*-modules`) 模式匹配自动拦截系统非 GUI 依赖包。

- **Uninstall 应用完全卸载增强**：
  - **NPM 全局包完全卸载**：支持扫描 (`npm list -g --json`) 与擦除 (`npm uninstall -g`) NPM 全局 CLI 工具（如 `@openai/codex`、`@cloudbase/cli`、`miniprogram-ci`），并自动清除空 Scope 目录。
  - **Standalone Native CLI 动态探测**：实现了零硬编码的独立 CLI 与 AI Coding 工具（如 **Claude Code** `~/.local/share/claude`、**Kimi Code** `~/.kimi-code`、**Grok CLI** `~/.grok`）的动态感知识别与干净彻底卸载。

- **DNF5 架构与包管理器缓存优化**：
  - **DNF5 原生支持**：深度兼容 Fedora 41/44+ 新一代 DNF5 架构，自动感知并解析 `/var/cache/libdnf5` 与 `/var/cache/dnf5daemon-server` 缓存路径。
  - **软件源元数据索引保护**：在 DNF / DNF5 中严格执行 `clean packages` 策略，仅清理占大头的废弃 `.rpm` 软件包，**保留元数据索引**，彻底解决每次清理后 `sudo dnf update` 重新漫长下载索引的问题。
  - **物理差额精确统计**：清理前后通过物理目录差额统计，真实精确汇报包管理器回收的空间。

- **Analyze Disk 磁盘分析层级与视觉重构**：
  - **根视图纯净层级**：从 Analyze Disk 根视图中排除系统级 `Dnf Cache` 与重复的 `Flatpak App Data` (`~/.local/share/flatpak`)，消除数据库索引干扰与双重计数。
  - **精细化分类图标**：为 Linux Insights 赋予专属视觉图标（`📦` 包管理器/Flatpak、`🐳` Docker、`🤖` AI 模型、`🕒` 旧文件）。

- **跨发行版深度兼容 (DEB & RPM)**：
  - **多发行版平滑感知**：完善了 Fedora/RHEL (RPM/DNF/DNF5)、Ubuntu/Debian (DEB/APT/dpkg)、Arch Linux (Pacman)、Snap 和 Flatpak 的全套生命周期管理。
