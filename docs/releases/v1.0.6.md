# Topo v1.0.6

Topo v1.0.6 is a major performance, security, and build infrastructure release introducing pure static Musl Rust engine binaries, readelf static ELF assertions, GPG Fail-Closed supply chain assurance, comprehensive dead code elimination with Vulture CI gating, multi-stage analyze deduplication, and single-pass disk traversal optimizations.

## Highlights

### Pure Static Musl Binary & Zero-glibc Cross-Distro Compatibility
- **Pure Static Musl Targets (`x86_64-unknown-linux-musl` / `aarch64-unknown-linux-musl`)**: Upgraded Topo's Rust core engine targets to pure static Musl binaries using `houseabsolute/actions-rust-cross@v0`, completely eliminating `glibc` (`libc.so.6`) runtime dependencies and making Topo 100% compatible out-of-the-box across all Linux distributions (including Alpine Linux, RHEL 7/8/9, Fedora, Debian, and Ubuntu).
- **Hardened ELF Static Assertions (`readelf`)**: Integrated automated CI checks verifying binary machine architecture (`readelf -h`), asserting zero `PT_INTERP` dynamic linkers (`readelf -l`), and asserting zero `DT_NEEDED` dynamic library dependencies (`readelf -d`).
- **GPG Fail-Closed Supply Chain Assurance**: Fully preserved the complete release asset bundle (`SHA256SUMS`, `SHA256SUMS.asc`, `topo-core-x86_64`, `topo-core-aarch64`, `install.sh`, and `topo-src.tar.gz`) with Fail-Closed GPG key verification, preventing releases if signing keys are absent.

### Comprehensive Dead Code Wipe & Vulture CI Gate
- **Complete Zero-Invocation Code Cleanse**: Purged unused attributes (`found_projects`, `found_artifacts`), dead variables (`requires_sudo`, `reaped`, `bat_pct_str`), dead constants (`EARTH`, `FAIL`, `CLEAN_ORPHAN_AGE_DAYS`), unused function (`safe_vacuum_sqlite`), and legacy selector class (`CleanSelector`).
- **Minimal Whitelist & Dual Gate Enforcement**: Refined `.vulture_whitelist.py` to strictly allow only dynamically registered optimization tasks and `__exit__` context signatures. Integrated Vulture dead code checks into both `./check.sh` pre-commit and `.github/workflows/ci.yml`.

### High & Medium Risk Performance & I/O Optimizations (Audit 2.1 - 2.9)
- **Analyze Overlapping Scan Deduplication & Symlink Key Normalization**: Implemented a 5-tier deduplication scheduler, capped scan concurrency to 2 workers, and fixed `ScanCache` LRU eviction bounds (1024 entries / 64 MiB max). Standardized path normalization (`_normalize_scan_path`) across Rust engine calls and cache lookup keys, fixing size 0 bugs on symlinked targets (e.g. `~/.cache`).
- **Single-Pass Age Cleanup (`--stats`)**: Extended Rust engine with `--stats` mode to calculate total size, non-zero file counts, and maximum activity times in a single pass, eliminating double tree traversal on stale directories.
- **Pre-indexed App Residue Search**: Introduced `_pre_scan_search_roots()` in `app_manager.py` to build read-only memory indices of XDG and Home root directories, reducing residue lookup complexity to O(1) memory ops.
- **Project Purge & System Optimization Streamlining**: Converted project discovery to generator consumption with path deduplication and sub-path pruning. Capped system optimization concurrency to 4 workers and transparently surfaced task failure tracebacks.
- **Compiled Static Protection Rule Caching**: Added LRU compiled caching (`_compiled_home_protection_paths`, `_compiled_whitelist_paths`, and `_resolved_desktop_app_cache_paths`) to prevent repetitive `resolve()` disk IO lookups during whitelist checks.

# Topo v1.0.6 中文重点

Topo v1.0.6 为 Topo 的性能重构、安全供应链与构建基础设施重大版本，重点引进了 Musl 纯静态 Rust 原生引擎、readelf 静态 ELF 校验断言、GPG Fail-Closed 零信任供应链防护、Vulture 死代码清洗与 CI 自动化门控、Analyze 多阶去重调度以及单遍磁盘遍历性能优化。

### 核心改进

- **Musl 纯静态二进制与零 glibc 跨发行版 100% 零依赖兼容**：
  - **Musl 纯静态编译 (`x86_64` / `aarch64`)**：采用 `houseabsolute/actions-rust-cross@v0` 交叉编译工具链将核心 Rust 引擎打包为纯静态 Musl 二进制，彻底摆脱对宿主系统 `glibc` (`libc.so.6`) 的运行依赖，实现 Alpine Linux、RHEL/CentOS 7/8/9、Fedora、Debian、Ubuntu 等所有 Linux 发行版的零依赖开箱即用。
  - **readelf 静态 ELF 依赖硬核断言**：在 CI 中增加了对 ELF 硬件架构 (`readelf -h`)、无 `PT_INTERP` 动态解释器 (`readelf -l`) 及无 `DT_NEEDED` 动态库依赖 (`readelf -d`) 的自动化校验。
  - **GPG Fail-Closed 零信任供应链防护**：完整保留 GitHub Release 的 `SHA256SUMS`、`SHA256SUMS.asc`、`topo-core-*` 独立引擎、`install.sh` 及 `topo-src.tar.gz` 发布资产，并在密钥缺失时实施 Fail-Closed 强行阻断。

- **全量死代码清洗与 Vulture 双重门控**：
  - **零调用死代码全量擦除**：清理了 `found_projects`、`found_artifacts` 废弃属性，`requires_sudo`、`reaped`、`bat_pct_str` 未使用变量，`EARTH`、`FAIL`、`CLEAN_ORPHAN_AGE_DAYS` 死常量，`safe_vacuum_sqlite` 死函数以及 `CleanSelector` 废弃选择器类。
  - **精简白名单与 CI 门控**：收紧 `.vulture_whitelist.py` 仅保留动态注册任务与 `__exit__` 协议签名，并在 `./check.sh` 与 GitHub Actions CI 中引入自动化 Vulture 死代码拦截。

- **高/中风险性能与磁盘 I/O 极速降频 (性能审查 2.1 - 2.9)**：
  - **Analyze 重叠扫描去重与符号链接 key 对齐**：实现五阶去重调度，并发降至 2，优化 `ScanCache` LRU 容量（1024 条 / 64 MiB 上限）；统一路径规范化 (`_normalize_scan_path`) 解决软链接目录（如 `~/.cache`）探测误报为 0 的问题。
  - **按年龄清理单遍遍历 (`--stats`)**：扩展 Rust 引擎 `--stats` 模式一次性计算总大小与最大活动时间，消除了陈旧目录扫描两遍的开销。
  - **应用残留预索引内存匹配**：引入 `_pre_scan_search_roots()` 预建立 XDG 及 Home 目录内存索引，将残留查找降为 O(1) 内存操作。
  - **Project Purge 与系统优化流式重构**：项目发现改为生成器流式消费，实现路径去重与父子归并，磁盘扫描并发降至 2；系统优化并发上限收紧为 4 且异常透明化输出。
  - **静态保护规则预编译缓存**：引入 `_compiled_home_protection_paths` / `_compiled_whitelist_paths` / `_resolved_desktop_app_cache_paths` 的 LRU 编译缓存，避免海量重复的 `resolve()` 磁盘 IO 节点查询。
