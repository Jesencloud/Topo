# Topo v1.0.5

Topo v1.0.5 is a major security hardening, supply chain trust-chain closure, ancestor directory path traversal defense, control-character sanitization, package installer safety, and comprehensive test suite update release. It eliminates all security vulnerabilities (critical/high/medium/low) identified across 10 rounds of security audits, completes end-to-end GPG signature verification for installer and binary assets, hardened multi-level ancestor paths for privileged operations, neutralizes Trojan Source / ANSI escape sequence injection vectors, deprivileges package post-installation scripts, corrects self-uninstallation path-protection boundary conflicts, and expands automated unit test coverage from 319 to 369 clean passing tests.

## Highlights

### Supply Chain Integrity & GPG Signature Closure (`H-2`, `M-5`)
- **End-to-End Verification Flow (`install.sh` & `update.py`)**: Completely eliminated unsigned Git checkout/reset installation branches for unverified refs. All script installations now mandate downloading signed `topo-src.tar.gz` source archives and validating both GPG signatures (`SHA256SUMS.asc` against pinned release key fingerprints) and SHA256 digests prior to archive extraction.
- **Native Engine Binary Verification**: Removed bypass logic that used unverified bundled binaries in `src/core/bin/`. All native `topo-core-*` binaries must match `SHA256SUMS` manifests before execution.
- **Transactional Staged & Minimal Installations**: Installations and updates now execute inside temporary isolation directories (`~/.topo.install.XXXXXX`) and atomically activate via `mv`. Automatically purges non-essential development, testing, and packaging files (`install.sh`, `check.sh`, `packaging/`, `pyproject.toml`, `README.zh-CN.md`, `assets/*.asc`) post-installation, leaving only essential runtime binaries and audio assets.

### Privileged Operations & Ancestor Path Hardening (`H-1`, `H-3`)
- **Ancestor Directory Verification (`analyze.py`)**: Hardened privileged `rm -rf --one-file-system` calls in `_sudo_remove()` to verify ownership and permissions across every parent directory component. Rejects untrusted, user-writable, or unprivileged-group-writable intermediate directories to block symlink-replacement privilege escalations.
- **Sticky Shared Directory Support**: Fully supports Linux Sticky-Bit shared directories (e.g. `/tmp`, where `stat.S_ISVTX` is set on the immediate parent), guaranteeing safe deletion for targets under `/tmp` while maintaining a strict defense against intermediate directory replacement.
- **Sudoers Path Whitelist Validation (`system.py`)**: Enforced strict regex whitelist validation (`_SAFE_SUDOERS_PATH_RE`) for passwordless sudo path configurations, restricting commands to exact, parameter-bounded binaries (`/usr/sbin/fstrim -a` and `/usr/bin/journalctl --vacuum-time=3d`).

### Control Character, ANSI Injection & BiDi Sanitization (`M-10`, `N-4`, `L-6`)
- **Architecture Decoupling & Display Sanitization (`text.py`)**: Extracted `sanitize_for_display()` into `src/core/text.py` to prevent cross-layer dependency violations. Neutralizes ANSI CSI escape sequences, C0/C1 control codes, Unicode line/paragraph separators (`U+2028` / `U+2029`), and BiDi directional override characters (`U+202A`~`U+202E`, `U+2066`~`U+2069`, mitigating Trojan Source / CVE-2021-42574).
- **TUI & Non-TUI Coverage**: Applied sanitization across 10 TUI selector components and 15 non-TUI `print()` output paths (`analyze.py`, `lock.py`, `apps.py`, `app_manager.py`).
- **Audit Log Escaping (`file_ops.py`)**: Updated `_sanitize_audit_field` to convert raw control characters into escaped `\xNN` and `\uNNNN` representations, ensuring `cat` and `less -r` log inspections are 100% injection-safe.

### Delete Safeguards, Lock Security & Installer Hardening (`M-1`, `M-3`, `M-6`, `M-8`, `M-11`, `L-1`, `L-7`)
- **Explicit Consent for Permanent Fallbacks (`M-1`)**: Replaced silent automatic fallback from Trash to permanent deletion in `analyze.py` with an explicit consent requirement (`allow_permanent_fallback`).
- **Narrowed `/var` Carve-Out Boundaries (`M-3`)**: Narrowed system carve-out checks in `whitelist.py` (`is_system_cleanable_content`) to require explicit package cache sub-directories under `/var/cache` and current-user ownership under `/var/tmp`.
- **Symlink Defense & Lock Hardening (`M-6`, `M-8`)**: Applied `O_NOFOLLOW` flags in `lock.py` (`SingleInstanceLock` and `is_file_locked()`) to prevent symlink-based lock attacks, enforcing lock-before-truncate file operations.
- **Package Script Deprivileging (`M-11`)**: Updated `packaging/scripts/after-install.sh` to execute file creation through `runuser` under `$target_user` instead of writing files directly as root.
- **Audit Log Permissions (`L-7`)**: Hardened deletion audit log creation (`_prepare_audit_log()`) with `O_NOFOLLOW` and strict `0700` / `0600` directory and file mode enforcement.
- **Self-Uninstallation Unblocking (`topo remove`)**: Introduced `allow_self_removal` in `file_ops.py` (`validate_path_for_deletion` and `safe_remove`), enabling `topo remove` to cleanly uninstall Topo's own installation and configuration files without triggering self-protection blocks, while maintaining 100% hard protection over `~/.ssh`, `~/.gnupg`, `~/Documents`, and user whitelists.

### Test Suite & Pre-Commit Quality Gate Expansion
- **Unit Tests Expanded (319 ➔ 369 Tests)**: Added 50 comprehensive unit tests covering supply chain signature verification, ancestor path traversal rejection, sticky bit handling, BiDi control character sanitization, POSIX lock contention, package installer deprivileging, and self-uninstallation boundaries.
- **Tach Architecture Boundary Gate**: Integrated `tach check` into `./check.sh` to automatically enforce strict module dependency boundaries across `src.core`, `src.clean`, and `src.ui`.

# Topo v1.0.5 中文重点

Topo v1.0.5 为 Topo 的全量安全加固、供应链完整信任闭环、祖先路径提权防御、控制字符与 BiDi 净化、安装脚本安全防线、自身卸载护栏修正及单元测试大版本。实现了包含 GPG 签名与 SHA256 摘要的供应链闭环校验、多层祖先路径校验、Trojan Source / ANSI 注入防御、安装脚本降权运行、自身卸载逻辑修复，并将单元测试由 319 项扩充至 369 项全绿通过。

### 核心改进
1. **供应链完整信任闭环 (`H-2`, `M-5`)**：`install.sh` 与 `update.py` 全面废弃未签名的 Git 路径，所有安装与更新强制下载 signed `topo-src.tar.gz` 源码包，在解压前必须使用钉死的发布密钥校验 GPG 签名 (`SHA256SUMS.asc`) 和 SHA256 摘要。原生 `topo-core-*` 引擎二进制强制全路径匹配摘要，采用暂存隔离与故障自动回滚机制。安装完成后自动清理 `install.sh`, `check.sh`, `packaging/`, `pyproject.toml`, `README.zh-CN.md`, `assets/*.asc` 等开发与包配置，保持运行目录极致纯净。
2. **提权面路径保护与祖先目录校验 (`H-1`, `H-3`)**：`analyze.py` 的 `_sudo_remove()` 在 root 提权删除前对所有祖先目录进行属主和权限复验，拒绝可被中间人替换的可写目录；兼容 Sticky-Bit 共享目录（如 `/tmp`）；`system.py` 严格使用正则白名单校验 sudoers 路径与参数。
3. **控制字符、ANSI 注入与 BiDi 净化 (`M-10`, `N-4`, `L-6`)**：抽取 `src/core/text.py` 净化模块，全面中和 ANSI CSI 序列、C0/C1 控制码、Unicode 行/段分隔符（`U+2028` / `U+2029`）与 BiDi 双向控制符（防范 Trojan Source / CVE-2021-42574）；审计日志输出自动转义为 `\xNN` / `\uNNNN`。
4. **删除护栏、锁文件与卸载修正 (`M-1`, `M-3`, `M-6`, `M-8`, `M-11`, `L-7`)**：取消回收站不可用时的无感知静默强删；收紧 `/var` 豁免边界；锁文件强制使用 `O_NOFOLLOW` 拒绝软链接；`after-install.sh` 通过 `runuser` 降权写入；`topo remove` 修复了卸载自身时被硬保护误拦截的 Bug，同时保持对 `~/.ssh`、`~/.gnupg` 等敏感凭据的绝对死锁保护。
5. **单元测试与预提交门控**：单元测试增加 50 项（达 369 项），挂载 `tach check` 自动化依赖边界守护，全量预提交门控 `./check.sh` 100% 绿色 Pass。
