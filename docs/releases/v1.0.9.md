# Topo v1.0.9

Topo v1.0.9 is a quality, architecture, and maintenance release focusing on codebase simplification (removal of redundant `purge` command), unification of shared lifecycle helpers (threaded spinners and sudo authentication), package boundary hygiene, installer dependency validation, and terminal UI cursor stability across menu transitions.

---

## Highlights

### 1. Unified Sudo Authentication & Spinner Lifecycles
- **Shared Sudo Authentication Entry (`src/core/system.py`)**:
  - Unified duplicate `_authenticate_sudo_session()` implementations across `clean.runner` and `clean.optimize` into a single shared `system.authenticate_sudo_session(dry_run, *, request_subject, action)`.
  - Replaced module-level sudo choice aliases with `terminal_state.read_sudo_choice` and fixed `opt_log()` to render a red `✗` when an optimization task fails.
- **Unified Threaded Spinner Manager (`src/core/spinner.py`)**:
  - Consolidated duplicate background-thread spinner implementations across app scanning, app uninstallation, and system optimization into a single `threaded_spinner` context manager.
  - Replaced static sleeps with prompt `threading.Event.wait()` synchronization and shared `DEFAULT_SPINNER_FRAMES` across modules.

### 2. Removal of `purge` Command & Codebase Simplification
- **Streamlined Command Line Scope**:
  - Removed deprecated `topo purge` and `topo all` commands to maintain a crisp single-responsibility CLI model (deep cleanup in `clean`, disk discovery in `analyze`).
  - Removed `src/clean/project.py`, `PaginatedSelector`, and associated dead configuration options (`purge_search_paths`).

### 3. Packaging & Installation Enhancements
- **Clean Package Isolation**:
  - Removed maintainer scripts (`after-install.sh`, `after-remove.sh`) from DEB/RPM builds to ensure system packages strictly manage `/usr/lib/topo` and `/usr/bin/topo` without modifying the user's `$HOME` during installation/removal.
  - Retained user-space residue cleanup exclusively in user-invoked `topo remove`.
- **Installer Dependency Validation (`install.sh`)**:
  - Added explicit pre-flight checks for required dependencies (`curl`, `python3`, `packaging`) in `install.sh` and documented prerequisites in the README.

### 4. Terminal UI & Test Stability
- **Flicker-Free Cursor Depth Tracking (`src/core/terminal_state.py`)**:
  - Added depth-counted cursor visibility tracking (`_cursor_hidden_depth`) so nested views and selectors keep the cursor consistently hidden during menu transitions without transient cursor flashes.
- **Seed-Proof Residue Index Testing (`tests/test_uninstall.py`)**:
  - Pinned gram bucketing to a stable CRC32 hash within selectivity unit tests to prevent test flakiness caused by `PYTHONHASHSEED` randomization.
- **Dead Code and Signature Cleanups**:
  - Dropped unused parameters from `find_residue_paths()` and `_execute_main_router()`, removed unused `Navigator.DEL`, and deduplicated audio bell playback into `_play_sound()`.

---

# Topo v1.0.9 中文发布说明

Topo v1.0.9 是一个聚焦于架构精简、生命周期统一、打包规范与终端交互细节的质量维护版本。本次更新移除了冗余的 `purge` 指令、统一了多线程加载动画与 Sudo 鉴权入口、规范了系统包安装边界、完善了安装脚本依赖校验，并修复了菜单跳转时的光标闪烁问题。

---

## 核心亮点

### 1. 统一 Sudo 鉴权入口与多线程加载动画（Spinner）
- **统一 Sudo 鉴权抽象（`src/core/system.py`）**：
  - 合并了 `clean.runner` 与 `clean.optimize` 中重复的 Sudo 鉴权逻辑为统一的 `system.authenticate_sudo_session(dry_run, *, request_subject, action)` 接口，保持各模块提示语定制能力的同时消除了代码冗余。
  - 修复了 `opt_log()` 在优化任务返回失败时错误渲染绿色对勾的问题，准确呈现红色 `✗`。
- **统一多线程动画生命周期（`src/core/spinner.py`）**：
  - 提炼 `threaded_spinner` 上下文管理器，统一了应用扫描、应用卸载和系统优化中的后台动画线程管理。
  - 使用 `threading.Event.wait()` 替代固定 sleep，实现即时退出响应，并在各模块间统一共享 `DEFAULT_SPINNER_FRAMES` 盲文字符序列。

### 2. 移除冗余的 `purge` 命令与代码精简
- **清晰明确的命令职责划分**：
  - 移除已废弃的 `topo purge` 以及仅用于组合执行的 `topo all` 指令，使命令职责更为明确：深度清理统一归属 `clean`，磁盘大文件发现归属 `analyze`。
  - 彻底清理 `src/clean/project.py`、`PaginatedSelector` 以及配置文件中无用的 `purge_search_paths` 等死代码。

### 3. 安装与系统打包规范化
- **系统包避免越权修改用户主目录**：
  - 移除 DEB/RPM 打包中的 `after-install.sh` / `after-remove.sh` 脚本，确保由 root 权限执行的系统包安装仅管理 `/usr/lib/topo` 与 `/usr/bin/topo`，禁止在安装/卸载过程中修改普通用户的 `$HOME` 目录。
  - 用户配置与数据清理明确保留在用户主动执行的 `topo remove` 命令中。
- **安装脚本前置依赖校验（`install.sh`）**：
  - `install.sh` 增加对系统依赖（`curl`、`python3`、`packaging`）的前置检测与友好错误提示，并同步完善了中英文 README 运行要求。

### 4. 终端 UI 与测试稳定性优化
- **基于深度计数的终端光标状态管理（`src/core/terminal_state.py`）**：
  - 为 `hide_cursor()` 和 `show_cursor()` 引入嵌套深度计数（`_cursor_hidden_depth`），确保在主菜单与各级子选择器嵌套跳转时，光标保持隐藏状态，彻底消除切换间隙的光标闪烁。
- **单元测试抗随机种子干扰（`tests/test_uninstall.py`）**：
  - 在卸载残留索引的候选筛选率测试中，通过局部 CRC32 替代随机化的 `PYTHONHASHSEED` 字符串哈希，彻底杜绝小概率测试用例偶发失败。
- **死代码与参数清理**：
  - 清理 `find_residue_paths()` 和 `_execute_main_router()` 中的未用参数，移除多余的 `Navigator.DEL` 属性，并将按键音效统一由 `_play_sound()` 处理。
